# Healthy Life Chatbot

A simple Arabic chatbot that gives general healthy life tips (water, sleep, food, exercise). It runs in the terminal and uses the Gemini API.

## What it does
- Chats in Arabic
- Remembers the conversation
- Tries again if the server is busy
- Does not give medical diagnosis

## Built with
Python, Gemini API (google-genai)

## How to run
1\ Install: pip install -r requirements.txt
2\ Make a .env file and write GEMINI_API_KEY=your_key
3\ Run: python chat.py
